BLOCK D · CHAPTER 16 / 20

醫學 RAG 與 Agentic AI

MedRAG、i-MedRAG、MedAgents、MIRAGE benchmark——把 LLM 變成可靠醫療助理的關鍵。

MedRAG, i-MedRAG, MedAgents, MIRAGE benchmark — what makes LLMs trustworthy medical assistants.

動機

LLM 知道的不夠，而且會幻覺

LLM 的兩大臨床罩門：(1) 知識截止——預訓資料有日期，新指引 / 新藥 / 新試驗一律未知；(2) 幻覺——會編造 PubMed 編號、編造劑量。RAG (Retrieval-Augmented Generation) 解法：每次提問先到外部知識庫（PubMed、UpToDate、ICD、formulary）檢索相關段落，再讓 LLM 在這些段落基礎上回答。

2024 起，RAG 與 Agentic AI 結合：LLM 主動規劃多次檢索、調用工具（計算機、SNOMED、藥物資料庫），把多步推理拆成可驗證的小步——這就是 MedAgents / i-MedRAG 的核心想法。

benchmark

MIRAGE：第一個大型醫療 RAG benchmark

2024 ACL Findings, Xiong et al. MIRAGE 包含 7,663 個來自 5 大醫療 QA 資料集的問題；同時推出 MedRAG toolkit，跨 41 種 corpus × retriever × LLM 組合做 1.8T token 大規模實驗。重要發現：

  • MedRAG 把 6 種 LLM 在 MedQA 提升 達 18%。
  • MedRAG boosts six LLMs on MedQA by up to 18%.
  • GPT-3.5 + MedRAG 接近 GPT-4 級別，Mixtral 同理。
  • GPT-3.5 / Mixtral + MedRAG approach GPT-4 levels.
  • 出現「log-linear scaling」與「lost-in-the-middle」效應——retrieve 太多反而退步。
  • "Log-linear scaling" + "lost-in-the-middle" effects emerge — retrieving too much hurts.
  • i-MedRAG（迭代追問）讓 GPT-3.5 在 MedQA 達 69.68%，勝過所有 prompt-engineering 與 fine-tune 法。
  • i-MedRAG (iterative follow-up) reaches 69.68% on MedQA with GPT-3.5 — beating all prompt engineering & fine-tuning.
架構

標準六段管線

索引建構

把 PubMed / UpToDate / 藥典切成 chunks，用 BiomedBERT / BGE-M3 嵌入後存進向量資料庫（Faiss / Milvus / Qdrant）。

Chunk PubMed / UpToDate / formulary; embed with BiomedBERT / BGE-M3; store in vector DB (Faiss / Milvus / Qdrant).

檢索

使用者 query → embed → top-k 段落。混合 BM25 + dense 通常勝過任一單獨方法。

Query → embed → top-k chunks. Hybrid BM25 + dense usually beats either alone.

重排序

用 cross-encoder（如 BGE-reranker）精篩 top-20 → top-5。

Use cross-encoder (e.g., BGE-reranker) to refine top-20 → top-5.

提示與生成

把片段塞進 prompt，要求 LLM 引用片段編號。

Inject snippets, require the LLM to cite snippet IDs.

自我審核 / 引用檢查

第二輪 LLM 檢查答案的每個 claim 是否確實對應到引用段落（claim-evidence alignment）。

Second LLM pass to verify every claim aligns with cited evidence.

迭代追問

若答案信心不足，LLM 自動生成 follow-up 問題，回到 step 2 再來一輪。

If confidence is low, LLM generates follow-ups and re-enters step 2.

Agentic AI

MedAgents：多代理協作

MedAgents 框架把醫療 QA 看成「多專家會診」：一個 LLM 扮演心臟科、一個扮演影像科、一個扮演藥師，彼此交換 evidence 與意見，最後由「主治醫師」整合。實驗顯示 MedAgents 在 MedQA、MedMCQA 上的多選題表現可顯著超越 single-LLM CoT。

更進階的設計是 tool-using agents：模型可以呼叫計算機（藥物劑量、eGFR）、查 Drugs.com、查臨床試驗、查 ICD/SNOMED 對應、執行 SQL on FHIR。LangGraph / OpenAI Assistants v2 / Anthropic MCP 是 2024-2026 主流框架。

MedAgents reframes medical QA as a "multi-specialist consult": one LLM plays cardiology, another radiology, another pharmacy; they exchange evidence and a "primary physician" synthesizes. Reported to significantly outperform single-LLM CoT on MedQA / MedMCQA.

More advanced: tool-using agents — the model invokes calculators (dosing, eGFR), Drugs.com, clinical-trial lookup, ICD/SNOMED mapping, SQL on FHIR. LangGraph / OpenAI Assistants v2 / Anthropic MCP are dominant frameworks 2024–2026.

實作

最小 MedRAG

# pip install langchain langchain-community faiss-cpu sentence-transformers
from langchain_community.embeddings import HuggingFaceEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_community.document_loaders import TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
docs = TextLoader("pubmed_chunks.txt").load()
chunks = RecursiveCharacterTextSplitter(chunk_size=400, chunk_overlap=40).split_documents(docs)
emb = HuggingFaceEmbeddings(model_name="BAAI/bge-m3")
db  = FAISS.from_documents(chunks, emb)
q = "What's the first-line therapy for HER2+ metastatic breast cancer in 2024?"
hits = db.similarity_search(q, k=5)
for h in hits: print(h.page_content[:200])
# Feed into your favorite LLM with prompt:
# "Answer using only the following snippets... Cite [1], [2]..."
library(reticulate)
lc <- import("langchain_community"); lcs <- import("langchain.text_splitter")
docs <- lc$document_loaders$TextLoader("pubmed_chunks.txt")$load()
splitter <- lcs$RecursiveCharacterTextSplitter(chunk_size=400L, chunk_overlap=40L)
chunks <- splitter$split_documents(docs)
emb <- lc$embeddings$HuggingFaceEmbeddings(model_name="BAAI/bge-m3")
db <- lc$vectorstores$FAISS$from_documents(chunks, emb)
hits <- db$similarity_search("HER2+ MBC first-line 2024", k=5L)
🚨
臨床安全紅線：「醫療 RAG」≠「醫療 AI 醫生」。即使 i-MedRAG 達 69.68%，仍有 30% 錯誤率；任何臨床落地都需要人類監督、引用可追溯、subgroup 公平性審計（見 Ch04 / Ch17）。 Clinical red line: medical RAG ≠ AI physician. Even i-MedRAG at 69.68% still has 30% error; deployments need human oversight, traceable citations, subgroup audits (Ch04 / Ch17).
