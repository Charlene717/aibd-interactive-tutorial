scGPT, Geneformer, scFoundation, UCE, CellFM — what happens when 33 million cells go through a Transformer?

觀念

從「pipeline」到「foundation」

傳統 scRNA-seq 流程是一條 12 步管線：QC → 標準化 → HVG → PCA → cluster → annotation → DE → integration。每一步換 dataset 就要重新調參。

單細胞 Foundation Model (scFM) 提供另一條捷徑：先在數千萬個未標註細胞上自監督預訓練，再把幾乎所有下游任務轉成「微調 / 零樣本嵌入查詢」。代表作有 scGPT（33M 細胞，Nature Methods 2024）、Geneformer、scFoundation、UCE、CellFM。

The classical scRNA-seq pipeline is 12 steps: QC → normalize → HVG → PCA → cluster → annotate → DE → integrate. Every new dataset means re-tuning.

Single-cell Foundation Models (scFM) offer a shortcut: pretrain on tens of millions of unlabeled cells, then turn nearly every downstream task into "fine-tune / zero-shot embedding lookup". Headliners: scGPT (33M cells, Nature Methods 2024), Geneformer, scFoundation, UCE, CellFM.

關鍵下游任務

scFM 能做的五件事

🏷️

① 零樣本細胞註釋

不需要訓練：把細胞嵌入到 reference embedding 空間做 k-NN 比對。HCA 已有 5000 萬細胞的 reference。

No training needed: embed cell and k-NN to a reference space. HCA already has a 50M-cell reference.

🔀

② 批次整合

大模型本身對 batch 不敏感；scGPT、scVI 都比 Harmony / BBKNN 更穩。

Large models are batch-robust; scGPT, scVI tend to beat Harmony / BBKNN.

🧠

③ 基因擾動 / KO 預測

Geneformer 可預測 in-silico knockout 後的細胞狀態變化；CZI rBio 把它做到 reasoning 等級。

Geneformer predicts post-knockout cell states; CZI rBio elevates this to reasoning-level.

💊

④ 藥物敏感性 / 反應

scGPT 在 GDSC / CCLE 微調可預測癌細胞株對特定化合物的反應。

Fine-tuned scGPT predicts response of cancer cell lines (GDSC, CCLE) to specific compounds.

🧫

⑤ 跨模態推論

CellFM 與 totalVI 由表現量預測 protein abundance；MultiVI 由 RNA + ATAC 聯合建模。

CellFM / totalVI predict protein abundance from expression; MultiVI jointly models RNA + ATAC.

⚠️

⑥ 注意：限制

scFM 對訓練分布外的 cell type 仍可能失準；2025 benchmark 也指出在「小資料集 / 高解析度狀態」上 scVI 仍有競爭力。不要盲信 zero-shot。

scFMs can still fail out-of-distribution; 2025 benchmarks show scVI is still competitive on small datasets / high-resolution states. Don't blindly trust zero-shot.

實作

scGPT 推論：把 AnnData 嵌入到 reference 空間

# pip install scgpt scanpy
import scanpy as sc, scgpt
adata = sc.read_h5ad("my_sample.h5ad")
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)
emb = scgpt.tasks.embed_data(adata,
        model_dir="./scgpt_whole_human",
        gene_col="feature_name",
        cell_type_key=None,
        return_new_adata=True)
sc.pp.neighbors(emb, use_rep="X_scGPT")
sc.tl.umap(emb)
sc.pl.umap(emb, color="leiden")
library(reticulate); library(Seurat); library(zellkonverter)
sce <- zellkonverter::readH5AD("my_sample.h5ad")
sc <- import("scanpy"); scgpt <- import("scgpt")
adata <- zellkonverter::SCE2AnnData(sce)
sc$pp$normalize_total(adata, target_sum=1e4)
sc$pp$log1p(adata)
emb <- scgpt$tasks$embed_data(adata, model_dir="./scgpt_whole_human",
            gene_col="feature_name", return_new_adata=TRUE)
seu <- CreateSeuratObject(counts=t(py_to_r(emb$X)))
seu[["scgpt"]] <- CreateDimReducObject(embeddings=py_to_r(emb$obsm["X_scGPT"]),
                                          key="SCGPT_", assay="RNA")
RunUMAP(seu, reduction="scgpt", dims=1:512)

想再深一點？scGPT 的 tokenization

scGPT 把一個細胞表達轉成 {gene_token, expression_bin} 對。基因 token 是 vocab 中 ~60K 基因 ID，表達 bin 把連續 log1p 表達分成 N 個離散等級。

x_cell → tokens = [(g₁, b₁), (g₂, b₂), ..., (gₖ, bₖ)]

pretraining 目標是「給定 cell 的部分 token，預測被遮蔽的 token」——類似 BERT 但條件是整個細胞的上下文。這讓模型學到「基因 X 與基因 Y 在這類細胞共表達」的cellular grammar。

Geneformer 用排序 (rank) tokenization：對每個細胞，根據表達量對 60K 基因排名，然後用 rank position 作為輸入。優點：對技術變異（library size、平台差異）天然 robust；缺點：失去絕對表達訊息。

scFoundation / UCE 走連續表達 + asymmetric encoder/decoder，保留更多表達細節，但對 batch effect 較敏感。沒有絕對最佳的 tokenization，因任務而定。

scGPT converts a cell's expression to {gene_token, expression_bin} pairs. Gene tokens are ~60K gene IDs; expression bins discretize log1p expression into N levels.

x_cell → tokens = [(g₁, b₁), (g₂, b₂), ..., (gₖ, bₖ)]

Pretraining objective: given partial tokens of a cell, predict masked tokens — like BERT but conditioned on the whole cell context. The model learns "gene X co-expresses with gene Y in this cell type" — a cellular grammar.

Geneformer uses rank tokenization: rank 60K genes by expression per cell, use rank position as input. Pros: robust to technical variation (library size, platforms); Cons: loses absolute expression.

scFoundation / UCE use continuous expression + asymmetric encoder/decoder, preserving more expression detail but more sensitive to batch effects. No single best tokenization — depends on task.

案例故事
2024-03 · Geneformer 在心衰預測

Geneformer 預測新心肌細胞基因擾動標的

Theodoris 等人（Nature 2023）用 Geneformer 做了一個漂亮實驗：用 30M 健康細胞 pretrain 後，在 cardiomyocyte 上 fine-tune，然後做in-silico knockout——預測敲掉每個基因會把細胞推向「健康」還是「衰竭」狀態。

模型挑出 100 個候選基因，其中 14 個被濕實驗驗證為新治療標的，包含一個過去從未被注意的 RNA-binding protein。其中一個基因被認為可能逆轉 dilated cardiomyopathy。

關鍵的工程細節：(1) 用 30M 細胞 pretrain 但只用 1500 個 patient cardiomyocyte fine-tune；(2) virtual knockout 是把該基因 rank 設為 0 後重新計算 attention；(3) 排序 tokenization 讓模型對 cardiomyopathy 樣本的技術變異 robust。

啟示：scFM 的真正價值不是「跑得更快的 UMAP」，而是「大規模 in-silico perturbation 篩選」——把 CRISPR screen 從「實驗 1 萬基因」變成「電腦先篩 1 萬，實驗驗證 100」。CZI rBio 2025 把這個範式更進一步。

Theodoris et al. (Nature 2023) ran a beautiful experiment with Geneformer: pretrain on 30M healthy cells, fine-tune on cardiomyocytes, then run in-silico knockout — predict whether silencing each gene would push cells toward "healthy" or "failing" state.

The model surfaced 100 candidate genes; 14 were validated as novel therapeutic targets in wet-lab experiments, including an RNA-binding protein never previously implicated, potentially reversing dilated cardiomyopathy.

Key engineering details: (1) pretrain on 30M cells but fine-tune on only 1,500 patient cardiomyocytes; (2) virtual knockout sets the gene's rank to 0 and recomputes attention; (3) rank tokenization keeps the model robust to cardiomyopathy-sample technical variation.

Takeaway: scFM's real value isn't "faster UMAP" — it's large-scale in-silico perturbation screening: turn a 10K-gene CRISPR screen into 10K computational + 100 experimental validations. CZI's rBio 2025 pushes this paradigm further.

教訓：scFM 的破壞性創新不在「跑 UMAP」，而在「pre-experimental virtual screening」——濕實驗成本壓縮 100×。
Lesson: scFM's disruptive value lies in pre-experimental virtual screening, not UMAP — wet-lab cost compressed 100×.

scFMsingle-cell Foundation Model
在數千萬細胞上自監督預訓的大型 Transformer，可零樣本或微調應用。
Large Transformer self-supervised on tens of millions of cells; supports zero-shot and fine-tuning.
Rank Tokenization排序 token 化
Geneformer 用：對每個細胞把基因按表達排名，rank position 作為 token。
Geneformer's approach: rank genes by expression per cell; use position as token.
In-silico Knockout虛擬基因敲除
不做實驗，由模型預測敲除某基因後的細胞狀態轉變。
No experiment — model predicts cell-state shift after knocking out a gene.
Batch Effect批次效應
同樣本不同實驗時間/平台造成的技術變異；Harmony / scVI / scGPT 都在處理。
Technical variation from different experimental batches/platforms; addressed by Harmony / scVI / scGPT.
UMIUnique Molecular Identifier
細胞條碼上的隨機序列，用來區分 PCR 重複 vs 真實分子。
Random sequences on cell barcodes that distinguish PCR duplicates from real molecules.
Doublet雙細胞
兩個細胞共用一個液滴的技術假象；Scrublet/DoubletFinder 偵測。
Two cells sharing one droplet; detected by Scrublet/DoubletFinder.
Cell Embedding細胞嵌入向量
scFM 為每個細胞輸出的 256–1024 維向量，是下游分析輸入。
256–1024-dim vector scFMs output per cell; input to downstream analysis.
Zero-shot Annotation零樣本註釋
不訓練，直接用 pretrained scFM 把細胞 embedding 後 k-NN 到 reference。
No training; embed cell with pretrained scFM and k-NN to a reference.
Probing探測
凍結 scFM 權重，只訓一個淺層分類器；介於零樣本與全微調之間。
Freeze scFM weights, train a small classifier on top; between zero-shot and full fine-tune.
HVGHighly Variable Genes
傳統 pipeline 選 2000-3000 高變異基因；scFM 可省略此步。
Classical pipelines pick 2,000-3,000 highly variable genes; scFMs often skip this step.
OODOut-of-Distribution
測試資料與訓練分布差異大；scFM 已知對 OOD cell type 失準。
Test data differs from training distribution; scFMs known to fail on OOD cell types.
Perturb-seq擾動測序
CRISPR + scRNA-seq；測量基因擾動對細胞轉錄組的影響。Geneformer 學的預測目標。
CRISPR + scRNA-seq; measures gene-perturbation effects on transcriptome. Geneformer's prediction target.
