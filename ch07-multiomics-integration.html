多體學整合與空間組

RNA + ATAC + 蛋白 + 空間位置——一個細胞的「全相」要怎麼用一個模型同時看？

RNA + ATAC + protein + spatial coordinates — how to view a cell's full picture through one model?

為何整合

一個細胞有多重身分

RNA 表現只告訴你「正在轉錄什麼」；ATAC 告訴你「染色質開放在哪裡」；CITE-seq 告訴你「細胞表面有什麼蛋白」；空間轉錄組告訴你「細胞跟誰當鄰居」。多體學整合的目標不是把訊號堆疊，而是學一個共同的潛在空間，讓不同模態互相校正、互相補位。

2024 起，scverse 生態（scvi-tools / Squidpy / SpatialData）讓多模態工作流終於有一致的資料容器與 API。

RNA tells you "what's being transcribed"; ATAC tells you "which chromatin is open"; CITE-seq tells you "surface proteins"; spatial transcriptomics tells you "who lives next to whom." The goal of multi-omics integration is not stacking signals but learning a shared latent space where modalities calibrate and complement each other.

Since 2024, the scverse ecosystem (scvi-tools / Squidpy / SpatialData) finally offers consistent containers and APIs for multi-modal workflows.

10x Visium / Stereo-seq

Gen 1, spot-level (~50 µm); analysis: deconvolution (cell2location, STdeconvolve).

Visium HD / Slide-seq v2

第二代，亞細胞至單細胞解析度；分析：Bayes / GNN spatial clustering（BayesSpace、SpaGCN）。

Gen 2, sub-cellular to single-cell; analysis: Bayes / GNN spatial clustering (BayesSpace, SpaGCN).

MERFISH / CosMx / Xenium

第三代，單分子原位定量；分析：細胞通訊（NCEM、COMMOT）、組織建模（Squidpy）。

Gen 3, single-molecule in situ; analysis: cell-cell communication (NCEM, COMMOT), tissue modeling (Squidpy).

實作

totalVI 整合 CITE-seq

import scvi, scanpy as sc
adata = sc.read_h5ad("citeseq.h5ad")
# adata.obsm['protein_expression'] holds ADT counts
scvi.model.TOTALVI.setup_anndata(adata,
    protein_expression_obsm_key="protein_expression",
    batch_key="batch")
m = scvi.model.TOTALVI(adata, latent_distribution="normal")
m.train(max_epochs=400)
adata.obsm["X_totalVI"] = m.get_latent_representation()
adata.obsm["denoised_protein"] = m.get_normalized_expression()[1]
library(reticulate); library(zellkonverter)

決策樹

該選哪個整合方法？

你的資料是？

RNA + ATAC→MultiVI（缺模態樣本）；GLUE / Pamona（無配對）。MultiVI (missing modality), GLUE / Pamona (unpaired).
CITE-seq→totalVI；經典分析 Seurat WNN。totalVI; classic Seurat WNN.
空間→SpatialGlue（多模空間 SOTA）；STAGATE / SpaGCN（純空間）。SpatialGlue (multi-modal spatial SOTA); STAGATE / SpaGCN (pure spatial).
想可解釋因子→MOFA+ / MEFISTO。MOFA+ / MEFISTO.
跨模零樣本→CellFM / SCIMITAR。CellFM / SCIMITAR.
