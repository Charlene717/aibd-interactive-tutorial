臨床預測與生存分析

Cox、DeepSurv、DeepHit、Time-to-event Transformer——存活時間與審查資料的 AI 化。

Cox, DeepSurv, DeepHit, time-to-event Transformer — AI for time-to-event and censored data.

基礎

生存分析特殊在哪？

普通迴歸假設你能觀察到所有結果。生存分析必須處理「審查 (censoring)」——某些病人在追蹤結束前還沒發生事件（死亡 / 復發 / 失敗），他們的真實時間是「至少 T」但未知。這個結構讓我們不能直接用 MSE 或交叉熵。

核心物件是 hazard function h(t|x) = P(T = t | T ≥ t, x)，以及 partial likelihood (Cox)。當 hazard 對 covariates 為線性時，是標準 CoxPH；用 DNN 取代線性層即 DeepSurv。

Ordinary regression assumes all outcomes are observed. Survival analysis must handle censoring: some patients haven't had the event by the end of follow-up; their true time is "≥ T". This structure forbids plain MSE / cross-entropy.

The core object is the hazard h(t|x) = P(T = t | T ≥ t, x) and the partial likelihood (Cox). When hazard is linear in covariates → standard CoxPH; replace the linear layer with a DNN → DeepSurv.

評估指標

五個必看指標

① C-index (Concordance)

把預測風險與實際存活時間配對是否一致；0.5 隨機、1.0 完美。最常用、但對重度審查不敏感。

Pairwise concordance between predicted risk and actual time; 0.5 random, 1.0 perfect. Common but insensitive to heavy censoring.

② Time-dependent AUC

固定 t* 的 ROC AUC，可看不同時間點區分能力。

ROC AUC at fixed t*, shows discrimination across horizons.

③ Brier Score / IBS

機率預測的均方誤差；IBS 是時間積分版本。低越好。

MSE of probability predictions; IBS integrates over time. Lower is better.

④ IPCW Adjustment

Inverse Probability of Censoring Weighting：校正審查機率對指標的偏差。

Inverse Probability of Censoring Weighting corrects for censoring bias.

⑤ Calibration Plot

觀察「預測 5 年存活」與「實際 5 年存活」的對齊。Hosmer-Lemeshow-like 檢定可量化。

Compare predicted vs observed 5-year survival; Hosmer-Lemeshow-style tests quantify miscalibration.

⑥ Decision Curve Analysis

不同 threshold 下的「淨效益 (net benefit)」。臨床導入前必看。

Net benefit across thresholds. A must-check before deployment.

實作

DeepSurv on TCGA

# pip install pycox lifelines
import torch, torchtuples as tt
from pycox.models import CoxPH
from pycox.evaluation import EvalSurv
net = tt.practical.MLPVanilla(in_features=512, num_nodes=[128,64],
                                  out_features=1, batch_norm=True, dropout=.3)
m = CoxPH(net, tt.optim.Adam(1e-3))
log = m.fit(x_tr, (dur_tr, evt_tr), batch_size=256, epochs=100,
            val_data=(x_va,(dur_va,evt_va)))
m.compute_baseline_hazards()
surv = m.predict_surv_df(x_te)
ev = EvalSurv(surv, dur_te, evt_te, censor_surv="km")
print("C-index:", ev.concordance_td(),
          "IBS:", ev.integrated_brier_score(np.linspace(0,dur_te.max(),100)))
library(survival); library(survminer); library(survivalmodels)
