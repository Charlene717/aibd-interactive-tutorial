From students new to AlphaFold to researchers running ColabFold, this is your protein-AI panorama:

  • Distinguish prediction (AlphaFold 2/3, ESMFold) vs design (RFdiffusion 3, ProteinMPNN, ESM-3)

兩條主線

預測 vs 設計：兩條互補的主線

蛋白質 AI 在 2024–2026 進入兩條同時推進的主線：(a) 結構預測，給序列得結構，AlphaFold 3 / ESM-3 / ESMFold 是代表；(b) 結構設計，從功能規格（binder、酶、symmetry）生出全新的蛋白序列+結構，RFdiffusion 3 / ProteinMPNN / Chroma 是代表。兩者常組合：先用 RFdiffusion 想出 backbone，再用 ProteinMPNN 鋪設 side chain，最後用 AF3 驗證。

Protein AI in 2024–2026 advances along two parallel tracks: (a) structure prediction — sequence to structure (AlphaFold 3, ESM-3, ESMFold); (b) structure design — generate sequences+structures from functional specs like binders, enzymes, symmetry (RFdiffusion 3, ProteinMPNN, Chroma). They often pair up: RFdiffusion proposes a backbone, ProteinMPNN designs side-chains, AF3 validates.

AlphaFold 3

AlphaFold 3

2024-05-08 Nature 630:493–500。AF3 用 擴散式 (diffusion) decoder 取代 AF2 的 IPA，在一個模型內聯合預測：蛋白質、核酸（DNA/RNA）、配體、離子、轉譯後修飾、抗體-抗原。

  • 配體結合姿態：勝過 AutoDock Vina 等專用 docking 工具。
  • Ligand binding pose: beats AutoDock Vina and other specialist docking tools.
  • 抗體–抗原預測：顯著勝過 AlphaFold-Multimer v2。
  • Antibody–antigen: substantially beats AlphaFold-Multimer v2.
  • 非商業免費 AlphaFold Server；2024 加開 inference code GitHub。
  • AlphaFold Server free for non-commercial; inference code open-sourced on GitHub later in 2024.

Published Nature 630:493–500 on 2024-05-08. AF3 replaces AF2's IPA with a diffusion decoder, jointly predicting proteins, DNA/RNA, ligands, ions, PTMs, antibody-antigen complexes in a single model.

目標

①→只要結構（小蛋白、快）：ESMFold。Structure only (small, fast): ESMFold.
②→結構 + 配體：AlphaFold 3（Server）；商業用可考慮 Boltz-1 / Chai-1。Structure + ligand: AlphaFold 3 (Server); commercial use → Boltz-1 / Chai-1.
③→設計 binder：RFdiffusion3 (backbone) → ProteinMPNN (seq) → AF3 (validate)。Binder design: RFdiffusion3 → ProteinMPNN → AF3.
④→穩定化已有蛋白：ProteinMPNN inverse folding。Stabilize existing protein: ProteinMPNN inverse folding.
⑤→抗體 CDR：IgLM / AntiFold。Antibody CDR: IgLM / AntiFold.
AlphaFold 2 解了「序列 → 結構」，AlphaFold 3 解了「分子 → 複合體」，RFdiffusion 3 解了「功能 → 序列」——下一個十年是「動態 → 機制」。 — Baker Lab consensus 2025
AlphaFold 2 solved "sequence → structure", AlphaFold 3 solved "molecules → complex", RFdiffusion 3 solved "function → sequence" — the next decade is "dynamics → mechanism". — Baker Lab consensus 2025

想再深一點？AF3 的 diffusion decoder

AF2 用 Invariant Point Attention (IPA) 直接迴歸原子座標。問題：IPA 訓練時需要嚴格的 frame-invariant 表徵，難以擴展到非標準殘基、配體、修飾。

AF3 改用擴散式 decoder：把目標座標加雜訊到純高斯，然後訓練一個 score network 學「如何去雜訊」。推論時從純雜訊取樣，逐步 denoise 到結構。優點：

  • 分子無關—天然處理蛋白質、DNA、RNA、配體、離子、修飾
  • 多樣取樣—一個輸入可生成多個結構，反映 conformational ensemble
  • 更穩定的訓練—diffusion loss 比 IPA 的 FAPE 更平滑

代價：(1) 推論慢（多個 denoising steps）；(2) 配體預測對 ligand database 偏差敏感；(3) 對「未見」配體 (cryptic binder) 仍有 hallucination 風險。

AF2 used Invariant Point Attention (IPA) to directly regress atom coordinates. Problem: IPA needs strictly frame-invariant representations, hard to extend to non-standard residues, ligands, modifications.

AF3 switched to a diffusion decoder: add noise to target coordinates → pure Gaussian, then train a score network to "denoise". At inference, sample from pure noise and iteratively denoise to a structure. Advantages:

  • Molecule-agnostic — naturally handles proteins, DNA, RNA, ligands, ions, modifications
  • Diverse sampling — one input yields multiple structures, reflecting conformational ensembles
  • More stable training — diffusion loss is smoother than IPA's FAPE

Costs: (1) slower inference (multiple denoising steps); (2) ligand prediction sensitive to ligand-database bias; (3) on "unseen" ligands (cryptic binders) hallucination risk remains.

案例故事
2024-2025 · Baker Lab + RFdiffusion 3

第一個被設計出來的 SARS-CoV-2 mini-binder

2022 年 David Baker 實驗室面臨挑戰：能否「從零設計」一個 100-aa 小蛋白，特異性結合 SARS-CoV-2 spike RBD？傳統做法靠 phage display 篩選千萬庫，耗時數月。

Baker 團隊用RFdiffusion + ProteinMPNN + AlphaFold 2 三件套：

  1. RFdiffusion—指定「結合 RBD 的某個 hotspot」作為條件，生成 1 萬個 candidate backbones
  2. ProteinMPNN—為每個 backbone 設計胺基酸序列
  3. AlphaFold 2—驗證每個設計是否會折成預期 backbone（pLDDT > 90 過關）
  4. 篩選 100 個送 yeast surface display 實驗驗證

結果：40 個有結合活性，9 個 KD < 100 nM。最強的 LCB1 mini-protein 在動物實驗中保護小鼠免於 SARS-CoV-2 感染（Cao et al. Science 2022）。

2025 RFdiffusion 3 升級：(1) 原子級設計（不只 backbone，連 side chain）；(2) 10× 速度；(3) 支援 DNA binder + 酶。Baker Lab 用它設計出第一個能催化新反應的 de novo 酶。

In 2022, David Baker's lab faced a challenge: could they design from scratch a 100-aa mini-protein that specifically binds the SARS-CoV-2 spike RBD? The classical approach (phage display screening of 10M libraries) takes months.

Baker's team used RFdiffusion + ProteinMPNN + AlphaFold 2:

  1. RFdiffusion — conditioned on "bind an RBD hotspot"; generated 10K candidate backbones
  2. ProteinMPNN — designed amino-acid sequences for each backbone
  3. AlphaFold 2 — validated each design folds to the intended backbone (pLDDT > 90)
  4. Top 100 sent to yeast surface display for experimental validation

Result: 40 had binding activity; 9 with KD < 100 nM. The strongest, LCB1, protected mice from SARS-CoV-2 infection (Cao et al. Science 2022).

2025 RFdiffusion 3 upgrades: (1) atom-level design (not just backbone — side chains too); (2) 10× speed; (3) supports DNA binders + enzymes. Baker Lab used it to design the first de novo enzyme catalyzing a novel reaction.

教訓：「設計 + 預測 + 驗證」三件套把蛋白設計從「篩選千萬」壓到「電腦設計 1 萬 + 實驗 100」，加速 100×。
Lesson: the "design + predict + validate" trio compresses protein design from "screen 10M" to "design 10K computational + 100 wet-lab", a 100× acceleration.

想得更深

Q1. AF3 能否完全取代 cryo-EM / X-ray？對「常規球狀蛋白」可，已是 protein-engineering 預設工具；對「動態構象 / 大複合體 / 膜蛋白」仍需實驗。參考：2024 Nature 「AF3 與 cryo-EM 互補」評論。
Q1. Can AF3 fully replace cryo-EM / X-ray?For routine globular proteins, yes — default protein-engineering tool now; for dynamic conformations / large complexes / membrane proteins, experiments still needed.Reference: 2024 Nature comment "AF3 and cryo-EM as complementary".
Q2. RFdiffusion 設計的蛋白真的能在實驗室合成嗎？2022 RFdiffusion 1 設計成功率約 20%；2025 RFdiffusion 3 提升到 ~60%。瓶頸不在設計，而在合成成本（GenScript $5-20/aa for codon-optimized expression）。策略：先 ProteinMPNN 改善 expressibility，再合成。
Q2. Are RFdiffusion designs really synthesizable?2022 RFdiffusion 1 success rate ~20%; 2025 RFdiffusion 3 ~60%. The bottleneck isn't design but synthesis cost (GenScript $5-20/aa for codon-optimized expression).Strategy: ProteinMPNN-improve expressibility first, then synthesize.
Q3. ESMFold (沒 MSA) vs AF2 (需 MSA)：誰是未來？Meta ESMFold 速度 10× 但精度略低；對新蛋白（orphan, novel）反而 ESMFold 更實用，因為找不到同源 MSA。混合：先 ESMFold 快篩，AF3 精算。
Q3. ESMFold (no MSA) vs AF2 (needs MSA): the future?Meta ESMFold is 10× faster but slightly less accurate; for orphan/novel proteins, ESMFold is more practical (no homologous MSA exists).Hybrid: ESMFold for screening, AF3 for refinement.
Q4. AF3 商業限制怎麼解？Google DeepMind AlphaFold Server 學術免費，商業需授權。2024 起 Boltz-1 (MIT)、Chai-1 (Chai Discovery) 釋出 AF3-replica 開源，授權友善。行動：商業用優先評估 Boltz-1 / Chai-1。
Q4. How to handle AF3's commercial restrictions?Google DeepMind AlphaFold Server is free for academic; commercial needs licensing. Since 2024 Boltz-1 (MIT), Chai-1 (Chai Discovery) released AF3-replicas open with friendly licenses.Action: commercial → evaluate Boltz-1 / Chai-1 first.
