蛋白質結構與生成設計

AlphaFold 3 / ESM-3 / RFdiffusion3 / ProteinMPNN——從預測到從零設計。

AlphaFold 3 / ESM-3 / RFdiffusion3 / ProteinMPNN — from prediction to de novo design.

兩條主線

預測 vs 設計：兩條互補的主線

蛋白質 AI 在 2024–2026 進入兩條同時推進的主線：(a) 結構預測，給序列得結構，AlphaFold 3 / ESM-3 / ESMFold 是代表；(b) 結構設計，從功能規格（binder、酶、symmetry）生出全新的蛋白序列+結構，RFdiffusion 3 / ProteinMPNN / Chroma 是代表。兩者常組合：先用 RFdiffusion 想出 backbone，再用 ProteinMPNN 鋪設 side chain，最後用 AF3 驗證。

Protein AI in 2024–2026 advances along two parallel tracks: (a) structure prediction — sequence to structure (AlphaFold 3, ESM-3, ESMFold); (b) structure design — generate sequences+structures from functional specs like binders, enzymes, symmetry (RFdiffusion 3, ProteinMPNN, Chroma). They often pair up: RFdiffusion proposes a backbone, ProteinMPNN designs side-chains, AF3 validates.

AlphaFold 3

AlphaFold 3

2024-05-08 Nature 630:493–500。AF3 用 擴散式 (diffusion) decoder 取代 AF2 的 IPA，在一個模型內聯合預測：蛋白質、核酸（DNA/RNA）、配體、離子、轉譯後修飾、抗體-抗原。

  • 配體結合姿態：勝過 AutoDock Vina 等專用 docking 工具。
  • Ligand binding pose: beats AutoDock Vina and other specialist docking tools.
  • 抗體–抗原預測：顯著勝過 AlphaFold-Multimer v2。
  • Antibody–antigen: substantially beats AlphaFold-Multimer v2.
  • 非商業免費 AlphaFold Server；2024 加開 inference code GitHub。
  • AlphaFold Server free for non-commercial; inference code open-sourced on GitHub later in 2024.

Published Nature 630:493–500 on 2024-05-08. AF3 replaces AF2's IPA with a diffusion decoder, jointly predicting proteins, DNA/RNA, ligands, ions, PTMs, antibody-antigen complexes in a single model.

決策樹

你的問題是？

目標

①→只要結構（小蛋白、快）：ESMFold。Structure only (small, fast): ESMFold.
②→結構 + 配體：AlphaFold 3（Server）；商業用可考慮 Boltz-1 / Chai-1。Structure + ligand: AlphaFold 3 (Server); commercial use → Boltz-1 / Chai-1.
③→設計 binder：RFdiffusion3 (backbone) → ProteinMPNN (seq) → AF3 (validate)。Binder design: RFdiffusion3 → ProteinMPNN → AF3.
④→穩定化已有蛋白：ProteinMPNN inverse folding。Stabilize existing protein: ProteinMPNN inverse folding.
⑤→抗體 CDR：IgLM / AntiFold。Antibody CDR: IgLM / AntiFold.

本章小測 (3 題)

1. AlphaFold 3 與 AF2 在架構上的關鍵差異是？

1. The key architectural difference between AF3 and AF2 is?

A. AF3 用 diffusion decoder 取代 IPAA. AF3 replaces IPA with a diffusion decoder
B. AF3 取消 MSA
C. AF3 改用 RNN
D. AF3 不需要 GPU
A 正解。diffusion decoder 讓 AF3 能同時建模蛋白-核酸-配體。A. Diffusion decoder lets AF3 jointly model protein-NA-ligand.

2. RFdiffusion3 相比前一代的優勢？

2. RFdiffusion3 over its predecessor?

A. 只能生成 α-helixA. Only generates α-helix
B. 原子級設計、10× 加速、支援 DNA binder 與酶B. Atom-level, 10× faster, supports DNA binders and enzymes
C. 取消開源
D. 不再需要 ProteinMPNN
B 正解。RFdiffusion3 是 2025 IPD 開源旗艦。B. RFdiffusion3 is the 2025 IPD open-source flagship.

3. ProteinMPNN 是用在哪個環節？

3. ProteinMPNN is used for?

A. 預測結構A. Structure prediction
B. Inverse folding：給結構→輸出序列B. Inverse folding: structure → sequence
C. 影像分割C. Image segmentation
D. GWAS
B 正解。ProteinMPNN 是設計流程的「鋪 side chain」步驟。B. ProteinMPNN is the "side-chain assignment" step in the design loop.
