醫療影像深度學習

U-Net 開啟、nnU-Net 工業化、MedSAM 走向 Foundation——醫療影像 AI 的完整工具箱。

From U-Net's birth to nnU-Net's industrialization to MedSAM's foundation era — the full toolbox.

任務地景

醫療影像四大任務

🎯

① 分類 / 偵測

整張影像 → 標籤（如 CheXpert 14 類胸 X 光、糖尿病視網膜病變）。模型常用 ResNet / ConvNeXt / ViT。

Image → label (CheXpert 14-class chest X-ray, diabetic retinopathy). Models: ResNet / ConvNeXt / ViT.

✂️

② 分割

每個 voxel/pixel → 類別（腫瘤、器官、病灶）。U-Net / nnU-Net 是黃金骨幹；3D 應用以 MONAI 為主流框架。

Voxel/pixel → class (tumor, organ, lesion). U-Net / nnU-Net are gold-standard backbones; MONAI is the mainstream 3D framework.

📏

③ 配準

把不同時間 / 模態的影像對齊。VoxelMorph、TransMorph，2024 起常與分割聯合訓練。

Align images across time/modality. VoxelMorph, TransMorph — since 2024 often jointly trained with segmentation.

🎨

④ 生成 / 重建

低劑量 CT 重建、MR 加速、跨模態合成（MRI→CT）。Diffusion / GAN / INR。Med-Diff、RoentGen 是熱門。

Low-dose CT reconstruction, MR acceleration, cross-modal synthesis (MRI→CT). Diffusion / GAN / INR. Med-Diff, RoentGen are popular.

陷阱

8 大常見陷阱

  1. DICOM 隱資訊洩漏：scanner ID、protocol、機構等成「捷徑特徵」，造成跨機構表現崩潰。
  2. DICOM metadata leakage: scanner ID, protocol, institution as shortcut features → cross-institution performance collapse.
  3. Spacing / orientation 未統一：3D 重採樣到固定 voxel spacing 是基本動作。
  4. Inconsistent spacing/orientation: resample 3D to fixed voxel spacing — must.
  5. Class imbalance：罕見器官 / 病灶 1% 也常見，需 Dice + Focal + 加權取樣。
  6. Class imbalance: rare organs/lesions ~1% — use Dice + Focal + weighted sampling.
  7. Test-time augmentation：TTA 通常加 0.5–2 個 Dice，很值得。
  8. Test-time augmentation: TTA usually adds 0.5–2 Dice points.
  9. Mask 標註不一致：多 annotator 重疊區可用 SoftDice / 多標籤合併。
  10. Inconsistent masks: multi-annotator overlap → SoftDice or merge.
  11. Domain shift：CT vs MRI 跨模、不同醫院。Test-time adaptation 與 federated learning（Ch19）救命。
  12. Domain shift: CT vs MRI, different hospitals. TTA & federated learning (Ch19) help.
  13. Hidden labels via reports：直接從 radiology report 抽取「弱標籤」要當心 noise。
  14. Weak labels from reports: noisy supervision — handle with care.
  15. Reproducibility：固定種子、版本化 DICOM、log 環境，否則 cross-center 重現極難。
  16. Reproducibility: fix seeds, version DICOM, log env — cross-center reproducibility is otherwise unrealistic.
