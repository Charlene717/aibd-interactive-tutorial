統計學習觀點

什麼是「機器在學」？

機器學習用一個簡單的方程式描述：給定資料 D = {(xᵢ, yᵢ)}，我們要找到函數 fθ 使得期望損失 𝔼[L(fθ(x), y)] 最小。關鍵在於三件事：模型族（function family）、損失函數、最佳化方法。

傳統統計與 ML 的差別是「先驗假設」程度——線性迴歸假設 y 是 x 的線性組合，深度學習則用組合式非線性逼近任意函數。但兩者共用同一套統計推論基礎：偏差–變異權衡（bias-variance tradeoff）、過擬合、交叉驗證。

One equation: given data D = {(xᵢ, yᵢ)}, find function fθ that minimizes expected loss 𝔼[L(fθ(x), y)]. Three ingredients: the model family, the loss function, the optimizer.

The classical-stats vs. ML divide is mostly about how strong the prior is — linear regression assumes a linear combination of x; deep nets use compositional nonlinearities to approximate arbitrary functions. They share the same statistical foundation: bias-variance tradeoff, overfitting, cross-validation.

基本元件

從感知器到 Transformer

📐

MLP / 全連接

萬能逼近器。生醫上常用於 tabular 資料（EHR baseline、SNP 風險分數）。注意 batch norm / dropout / 殘差連接。

Universal approximator. Used for tabular biomedical data (EHR baselines, SNP risk scores). Mind batch norm, dropout, residual connections.

🖼️

CNN

共享卷積核 → 平移不變、局部感受野。U-Net 是醫療影像分割的黃金骨幹。

Shared convolution → translation invariance, local receptive fields. U-Net is the gold backbone for medical image segmentation.

🔁

RNN / LSTM / Mamba

序列建模舊王。Mamba (2024) 結合 SSM 狀態空間，長序列更高效，已用於 Caduceus、Evo。

Old kings of sequence modeling. Mamba (2024) uses state-space models for long-sequence efficiency — adopted by Caduceus, Evo.

🎯

Transformer

自注意力捕捉任意距離相依。ESM、scGPT、Med-Gemini、AlphaFold 的核心。Multi-head + 位置編碼 + FFN。

Self-attention captures arbitrary-distance dependencies. The core of ESM, scGPT, Med-Gemini, AlphaFold. Multi-head + positional encoding + FFN.

🌊

Diffusion / Flow

逐步從雜訊還原成樣本。AlphaFold 3、RFdiffusion、生成分子用。Score matching 或 ODE flow 是核心。

Denoise step-by-step from noise. Used by AlphaFold 3, RFdiffusion, molecule generation. Score matching / ODE flows at the core.

🕸️

GNN

節點 + 邊的訊息傳遞。分子（atom + bond）、蛋白質殘基圖、PPI 網路、藥物–靶點交互作用都靠它。

Message passing on nodes + edges. Molecules (atoms+bonds), protein-residue graphs, PPI networks, drug-target interactions all use GNNs.

訓練的工程

把模型練好的 7 個工程關鍵

  1. 資料切分：訓練 / 驗證 / 測試一定要按「個案」而非「樣本」切，避免訊息洩漏。
  2. Data splits: split by subject, not sample, to avoid leakage.
  3. 學習率排程：cosine warmup → decay 是最穩的預設。
  4. LR schedule: cosine warmup → decay is the safest default.
  5. 批次大小：太小不穩、太大過度平均；BN 對小 batch 不友善，改 LayerNorm / GroupNorm。
  6. Batch size: too small unstable, too large over-averages; BN dislikes small batches — use LayerNorm/GroupNorm.
  7. 正則化：Dropout、Weight decay、Mixup、Label smoothing 是醫療影像四大常駐。
  8. Regularization: Dropout, weight decay, Mixup, label smoothing — four staples in medical imaging.
  9. 早停 (Early stopping)：驗證集為準。
  10. Early stopping: based on validation, not training.
  11. 類別不平衡：罕病 1:1000 是常態。Focal loss、class-balanced sampling、re-weighting 三件套。
  12. Class imbalance: rare disease 1:1000 is normal. Focal loss, class-balanced sampling, re-weighting — the trio.
  13. 可重現性：固定種子、記錄環境、版本化資料、log MLflow / W&B。
  14. Reproducibility: fix seeds, snapshot environments, version data, log with MLflow / W&B.

想再深一點？Bias-Variance 分解

對任意點 x，泛化誤差可分解為三項：

E[(y − ŷ(x))²] = (Bias[ŷ(x)])² + Var[ŷ(x)] + σ²

其中 Bias 衡量「模型族系統性偏離真實函數」，Variance 衡量「訓練資料微擾下模型輸出的波動」，σ² 是不可消除的雜訊。

  • 線性迴歸：高 bias、低 variance
  • k=1 的 kNN：低 bias、高 variance
  • 深度神經網路：兩者皆可調，但 2020 起 Belkin 的「double descent」現象指出，超大模型反而再降誤差——這就是現代 Foundation Model「越大越好」的部分理論基礎

Regularization（L1/L2、Dropout、Mixup、Early stopping）本質上是「用一點 bias 換很多 variance」的工程操作。
