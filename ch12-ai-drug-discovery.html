AI 藥物發現

從 virtual screening 到分子生成、從 ADMET 預測到自駕實驗室——藥物 R&D 的 AI 化全景。

From virtual screening to molecule generation, from ADMET to self-driving labs — the AI-fication of drug R&D.

新手友善 中階 進階補充

這一章你會學到什麼？

不管你是剛接觸藥物設計的學生、cheminformatics 老手，還是進入產業的研究員，這章是你的「AI 藥物 R&D 全景」：

  • 說出 AI 在「靶點識別 → 虛擬篩選 → 分子生成 → ADMET → SAR → 自駕實驗室」六大切入點
  • 分辨 SMILES、graph、3D conformer、ECFP 四種分子表徵的適用情境
  • 知道 AlphaFold 3、DiffDock、REINVENT 4、ADMET-AI、RDKit 何時用
  • 避開「AI 藥已上市」「電腦篩選一切搞定」迷思

From students new to drug design to cheminformatics veterans and industry researchers, this is your AI drug-discovery panorama:

  • Six AI entry points: target ID → virtual screening → molecule generation → ADMET → SAR → self-driving labs
  • Differentiate SMILES, graph, 3D conformer, ECFP representations
  • Know when to use AlphaFold 3, DiffDock, REINVENT 4, ADMET-AI, RDKit
  • Steer clear of "AI drug already on market" and "computational screening solves everything" myths
痛點

為什麼要 AI？$2.6B、10 年、90% 失敗率

業界共識：一款新藥從靶點識別到上市平均約 $2.6B、10–12 年；臨床階段 90% 失敗。AI 的角色不是取代化學家或醫師，而是壓縮各階段的「搜尋空間」與「假設驗證循環」——靶點識別、化合物設計、ADMET 預測、結構優化、臨床試驗模擬，逐段優化。

2024 起，藥物 AI 進入兩個新紀元：(1) Isomorphic Labs（AlphaFold 衍生）與 Novartis、Eli Lilly 簽下數十億美元合約；(2) Recursion + Exscientia 合併，「自駕實驗室」（self-driving labs）成為新範式。

Industry consensus: a new drug takes ~$2.6B and 10–12 years from target ID to market; ~90% fail in clinical phases. AI's role is not to replace chemists or clinicians but to compress the search space and the hypothesis-validation loop at each stage — target ID, molecule design, ADMET, lead optimization, trial simulation.

Since 2024, drug AI hits two new eras: (1) Isomorphic Labs (AlphaFold spin-off) signs multi-billion deals with Novartis and Eli Lilly; (2) Recursion + Exscientia merger turns "self-driving labs" into a new paradigm.

用 RDKit + ADMET-AI 評估候選分子

# pip install rdkit admet-ai
from rdkit import Chem
from rdkit.Chem import Descriptors, QED
from admet_ai import ADMETModel
m = ADMETModel()
smiles = ["CC(=O)Oc1ccccc1C(=O)O",  # aspirin
          "CN1C=NC2=C1C(=O)N(C(=O)N2C)C"]  # caffeine
df = m.predict(smiles=smiles)
print(df[["smiles","hERG","BBB_Martins","AMES","LD50_Zhu"]])
for s in smiles:
    mol = Chem.MolFromSmiles(s)
    print(s, "MW=", Descriptors.MolWt(mol),
              "QED=", round(QED.qed(mol),3))
library(reticulate); library(rcdk)
admet <- import("admet_ai")
m <- admet$ADMETModel()
smiles <- c("CC(=O)Oc1ccccc1C(=O)O", "CN1C=NC2=C1C(=O)N(C(=O)N2C)C")
df <- m$predict(smiles=smiles)
print(df[, c("smiles","hERG","BBB_Martins","AMES","LD50_Zhu")])

想再深一點？分子 GNN 訊息傳遞

D-MPNN（Directional Message Passing Neural Network, Yang 2019）把分子當無向圖：原子=節點、鍵=邊。每層更新：

m_v^(t+1) = Σ_{w∈N(v)} M_t(h_v^(t), h_w^(t), e_vw)
h_v^(t+1) = U_t(h_v^(t), m_v^(t+1))

關鍵 trick：用有向邊訊息而非節點訊息，避免「自我訊息洩漏」。Chemprop 庫實作此架構，在 ADMET 多任務上仍是 2024 SOTA。

3D Equivariant GNN（Equiformer, ViSNet, SchNet）多了「SE(3) 等變性」——原子位置旋轉/平移後，輸出表徵相應變化。優點：自然處理 3D conformer；缺點：訓練資料需要 3D 結構（QM9, GEOM-Drugs）。

D-MPNN (Directional Message Passing Neural Network, Yang 2019) treats molecules as undirected graphs: atoms = nodes, bonds = edges. Each layer updates:

m_v^(t+1) = Σ_{w∈N(v)} M_t(h_v^(t), h_w^(t), e_vw)
h_v^(t+1) = U_t(h_v^(t), m_v^(t+1))

Key trick: use directed edge messages not node messages, avoiding "self-message leakage". The Chemprop library implements this; still 2024 SOTA on multi-task ADMET.

3D Equivariant GNN (Equiformer, ViSNet, SchNet) adds SE(3) equivariance — atom positions rotate/translate, output features change correspondingly. Pros: handles 3D conformers naturally; Cons: requires 3D-structure training data (QM9, GEOM-Drugs).

案例故事
2020-2024 · Insilico Medicine ISM001-055

第一個 AI 分子進入 Phase II

2020 年 Insilico Medicine 用其 Pharma.AI 平台（PandaOmics 找 targets + Chemistry42 生成分子）鎖定 idiopathic pulmonary fibrosis (IPF) 的新標的 TNIK。整個流程：

  1. PandaOmics 靶點識別—多 omics + 知識圖譜，從 20K 個基因縮到 20 個候選；TNIK 被選中（過去未被視為 IPF 標的）
  2. Chemistry42 分子生成—生成 80 個 candidate molecules，AI 預測 IC50、ADMET
  3. 濕實驗驗證—合成 32 個，6 個有活性，ISM001-055 是冠軍
  4. Phase I 完成（2022）—健康志願者安全性 OK
  5. Phase IIa 開始（2024）—IPF 患者；2025 中期讀出

關鍵：從 target ID 到 Phase I IND 只花 18 個月，傳統流程要 4-6 年。成本估計 $2.6M USD（不含 phase II），是傳統的 1/10。

但要注意：「AI 設計」≠「AI 取代藥廠」。Insilico 仍需專業化學家、臨床團隊、$300M+ 募資、傳統 Phase III。AI 的真正貢獻在壓縮假設驗證循環，不是消除它。

In 2020 Insilico Medicine used its Pharma.AI platform (PandaOmics for targets + Chemistry42 for molecules) to nominate a novel target TNIK for idiopathic pulmonary fibrosis (IPF). The pipeline:

  1. PandaOmics target ID — multi-omics + knowledge graph narrowed 20K genes to 20 candidates; TNIK selected (previously not considered an IPF target)
  2. Chemistry42 molecule generation — 80 candidates with AI-predicted IC50, ADMET
  3. Wet-lab validation — 32 synthesized, 6 active, ISM001-055 won
  4. Phase I done (2022) — safety in healthy volunteers OK
  5. Phase IIa started (2024) — IPF patients; mid-2025 interim readout

Key: from target ID to Phase I IND in just 18 months; classical pipeline takes 4-6 years. Cost estimated ~$2.6M USD (excluding Phase II), 1/10 of classical.

But note: "AI design" ≠ "AI replaces pharma". Insilico still needs chemists, clinical teams, $300M+ funding, classical Phase III. AI's real contribution is compressing the hypothesis-validation loop, not eliminating it.

教訓：AI 藥物的革命不在「找到一個分子」，而在「18 個月 vs 6 年的速度差」。
Lesson: the AI drug revolution isn't "finding one molecule" — it's the 18-months-vs-6-years speed gap.

A. AI 提議 → 機器人合成 → 自動檢測 → AI 從結果學習 → 下一輪A. AI proposes → robotic synthesis → automated assay → AI learns → next round
B. 純粹 in-silico 不做實驗
C. 完全人工操作
D. 不需要 ML
A 正解。Active learning + 機器人實驗的閉迴路。A. Closed-loop active learning + robotic experimentation.
