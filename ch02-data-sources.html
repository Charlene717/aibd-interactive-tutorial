生醫大數據的類型與來源

在訓練模型之前，你需要先知道資料從哪裡來、長什麼樣子，以及隱私邊界在哪。

Before training a model, you need to know where data comes from, what it looks like, and where the privacy boundaries are.

概覽

生醫資料的四象限

把生醫大數據概念化的最快方法，是放在「分子 ↔ 個體」與「研究用 ↔ 臨床用」兩個軸上。每個象限的取得管道、隱私限制與適用模型都不同。

The fastest way to conceptualize biomedical big data is along two axes: "molecular ↔ individual" and "research ↔ clinical." Each quadrant differs in access, privacy and best-fit models.

分子層級個體層級
研究用 基因體（WGS、scRNA、ATAC）、蛋白體、代謝體；TCGA / GTEx / HCA / ENCODE 表型 + 影像 + 問卷；UK Biobank、All of Us、生統世代追蹤
臨床用 伴隨診斷分子檢測、循環腫瘤 DNA、單基因檢測 EHR（FHIR / OMOP CDM）、PACS 影像、穿戴裝置、Claims
關鍵公開資料集

十個你應該認識的資料庫

🧬 UK Biobank

50 萬英國成人，WGS + 1100 種血液生化、MRI、加速度計、EHR 連結。需申請 access；2024 起新增蛋白體 5400 種 Olink。

500K UK adults: WGS + 1,100 blood biomarkers + MRI + accelerometer + EHR linkage. Application required; 2024 added 5,400-target Olink proteomics.

🇺🇸 All of Us (NIH)

美國 1M+ 多樣族裔，WGS + EHR + 問卷 + 穿戴。2024 公布 245K WGS，亞裔、西語裔占比顯著高於 UK Biobank。

1M+ diverse Americans: WGS + EHR + surveys + wearables. 245K WGS released in 2024; markedly more Asian/Hispanic representation than UK Biobank.

🎗️ TCGA / GTEx

TCGA：33 癌種 11K 患者 multi-omics；GTEx v9：54 健康組織 17K bulk-RNA。是癌症 vs. 正常組織比較的金標準。

TCGA: 33 cancer types, 11K patients, multi-omics; GTEx v9: 54 tissues, 17K bulk RNA-seq. Gold standard for cancer-vs-normal comparison.

🔬 Human Cell Atlas (HCA)

>50M 細胞、跨 33 個器官；scGPT 與 Geneformer 的核心預訓練語料；CELLxGENE 提供 web 探索。

>50M cells across 33 organs; the core pretraining corpus for scGPT and Geneformer; explored via CELLxGENE.

📚 PubMed / PMC

3700 萬+ 文獻摘要、PMC 800 萬全文。BioBERT、PubMedBERT、Med-PaLM 2 預訓練語料。

37M+ abstracts; 8M PMC full-text. Pretraining source for BioBERT, PubMedBERT, Med-PaLM 2.

🧪 UniProt + AlphaFold DB

UniProt 2.5 億蛋白序列；AlphaFold DB 已涵蓋 200M+ 預測結構。ESM-2/3 / AF3 主要演進舞台。

250M protein sequences in UniProt; 200M+ predicted structures in AlphaFold DB. The main stage for ESM-2/3 / AF3.

🩻 MIMIC-IV / CheXpert / NIH Chest X-ray

MIMIC-IV：40 萬重症 EHR + 報告；CheXpert：22 萬胸 X 光；NIH ChestX-ray14：11 萬影像。臨床 NLP 與影像 DL 入門必備。

MIMIC-IV: 400K ICU EHR + reports; CheXpert: 220K chest X-rays; NIH ChestX-ray14: 110K images. Essential for clinical NLP & imaging DL.

📡 ENCODE / Roadmap Epigenomics

跨組織 ChIP-seq、ATAC、DNase。Enformer、Borzoi 的監督訊號來源。

Cross-tissue ChIP-seq, ATAC, DNase. The supervision signal for Enformer, Borzoi.

💊 ChEMBL / PubChem / BindingDB

ChEMBL：240 萬化合物、1900 萬生物活性；BindingDB：280 萬結合資料。藥物設計 ML 標配。

ChEMBL: 2.4M compounds, 19M bioactivities; BindingDB: 2.8M binding records. Standard for drug-design ML.

🌐 OMOP CDM / FHIR

不是資料集，而是標準格式。OHDSI 透過 OMOP CDM 串接全球 800M+ 患者紀錄做聯邦研究；FHIR 是 HL7 制訂的 RESTful 醫療資訊交換標準。

Not datasets but standards. OHDSI links 800M+ patient records globally via OMOP CDM; FHIR is HL7's RESTful health-data exchange standard.

實務工作流

申請到分析：四步驟

權限申請與 IRB

UK Biobank / All of Us / dbGaP 都需要 IRB 通過、研究計畫書與資料安全聲明。預留 2–4 個月。

UK Biobank, All of Us, dbGaP all require IRB approval, a research protocol, and a data security plan. Budget 2–4 months.

標準化與品質檢查

EHR → OMOP CDM / FHIR；影像 → 重採樣與 z-score；基因體 → GATK best practice + lift-over。記得跑 Outlier、Missingness、Cohort drift。

EHR → OMOP CDM / FHIR; imaging → resample + z-score; genomics → GATK best practice + lift-over. Always run outlier, missingness, cohort drift checks.

可重現環境與版本管理

用 Docker / Singularity 鎖環境；用 DVC / lakeFS / Pachyderm 追資料版本；Git LFS 不夠用。

Lock environments with Docker/Singularity; track data versions with DVC/lakeFS/Pachyderm; Git LFS is not enough.

去識別化與最小必要

HIPAA Safe Harbor 18 項識別子刪除；採資料最小化原則；高敏資料留在 enclave / TRE 不下載。

Remove the 18 HIPAA Safe Harbor identifiers; apply data minimization; keep sensitive data in enclaves / TREs without download.

程式碼

讀進 GTEx 表現量 + UK Biobank 表型

import pandas as pd, anndata as ad
# GTEx bulk RNA-seq matrix (TPM)
tpm = pd.read_csv("GTEx_v9_tpm.gct", sep="\t", skiprows=2, index_col=0)
meta = pd.read_csv("GTEx_v9_sample_attr.tsv", sep="\t", index_col=0)
adata = ad.AnnData(X=tpm.T.values, var=pd.DataFrame(index=tpm.index),
                  obs=meta.loc[tpm.columns])
# UK Biobank phenotype subset via DNAnexus / RAP
ukbb = pd.read_csv("ukbb_baseline.tsv", sep="\t")
print(adata, ukbb.shape)
library(data.table); library(SummarizedExperiment)
tpm  <- fread("GTEx_v9_tpm.gct", skip=2)
meta <- fread("GTEx_v9_sample_attr.tsv")
se <- SummarizedExperiment(assays=list(tpm=as.matrix(tpm[,-1:-2])),
                           rowData=tpm[,1:2], colData=meta)
ukbb <- fread("ukbb_baseline.tsv")
cat("se: ", dim(se), " | ukbb: ", dim(ukbb), "\n")
⚠️
常見坑：不同來源的 gene symbol 不一致（HGNC 名 vs Ensembl ID vs Refseq）。一定要先在 BioMart 或 mygene 跑一輪映射。 Common pitfall: gene symbols differ across sources (HGNC vs Ensembl ID vs Refseq). Always map via BioMart or mygene first.

本章小測 (3 題)

1. OMOP CDM 與 FHIR 最大的差別是？

1. The biggest difference between OMOP CDM and FHIR is?

A. OMOP 為「分析導向」標準（人口流行病學）；FHIR 為「交換導向」標準（API 即時資料）A. OMOP is "analytics-oriented" (epidemiology); FHIR is "exchange-oriented" (real-time APIs)
B. OMOP 只用於癌症B. OMOP is only for cancer
C. FHIR 是基因體格式C. FHIR is a genomics format
D. 兩者完全等價D. They are equivalent
A 正解。實務上常先 FHIR 收集，再 ETL 到 OMOP 做大規模研究。A. In practice, FHIR ingests; OMOP enables large-scale research.

2. 下列哪個資料來源最適合做跨族裔藥物反應研究？

2. Which dataset is most suitable for cross-ancestry drug response research?

A. TCGAA. TCGA
B. UK Biobank（94% 歐裔）B. UK Biobank (94% European)
C. All of Us（多樣族裔 + 處方紀錄）C. All of Us (diverse ancestry + prescription records)
D. ENCODED. ENCODE
C 正解。All of Us 設計上就強調少數族裔代表性。C. All of Us was designed for ancestry diversity.

3. HIPAA Safe Harbor 規定刪除幾種識別子？

3. HIPAA Safe Harbor mandates removal of how many identifiers?

A. 5
B. 10
C. 18
D. 33
C 正解。18 種識別子（姓名、地址、日期、電話、IP、生物特徵 …）。C. 18 identifiers (name, address, dates, phone, IP, biometrics …).
