基因體序列 AI

把 30 億個鹼基當成「語言」來建模——Enformer、Borzoi、Nucleotide Transformer、Caduceus 的世界。

Modeling 3 billion bases as a 'language' — the world of Enformer, Borzoi, Nucleotide Transformer, and Caduceus.

動機

DNA 為什麼可以被「語言模型」建模？

表面上 DNA 只有 4 個字母（A/C/G/T），但啟動子、增強子、剪接位、CpG 島等「文法」隱藏在序列中。距離可達 100 kb 以上的調控元件能影響一個基因的表現量——這正是 Transformer 「自注意力」最擅長捕捉的長程依賴。

傳統 motif 掃描或 PWM 只能看局部訊號；現代序列 AI 把整段 DNA 當作上下文，輸出可以是 chromatin accessibility、表現量、變異效應等多種「軌道 (tracks)」。

DNA has only 4 letters (A/C/G/T), but promoters, enhancers, splice sites, CpG islands hide an entire "grammar". Regulatory elements >100 kb away can modulate a gene's expression — exactly the long-range dependencies Transformer self-attention excels at.

Traditional motif-scanning or PWMs see only local signals; modern sequence AI treats long DNA as context and outputs many "tracks": chromatin accessibility, expression, variant effects, and more.

工作流

典型使用流程

選模型與 token 化

NT-v2 用 6-mer + BPE；Caduceus 用單字符。任務若涉及短距 motif，6-mer 更有效；涉及超長序列，單字符 + Mamba 更省。

NT-v2 uses 6-mer + BPE; Caduceus uses single-character. Short motifs → 6-mer; ultra-long → single-char + Mamba.

嵌入抽取或微調

少資料情境用 zero-shot 嵌入接線性分類器；資料夠用 LoRA / full FT。

Few-shot: zero-shot embeddings + linear probe; ample data: LoRA / full fine-tune.

變異效應預測（ISM）

在序列上做 ref vs alt 推論，記錄輸出差異作為 delta-score。

Run ref vs alt through the model; the output delta is the variant effect score.

與 GWAS / QTL 整合

用模型分數做 functional fine-mapping，或當作 PRS 的補充特徵。

Use scores for functional fine-mapping or as auxiliary features in PRS.

實作

用 Nucleotide Transformer 嵌入一段序列

# pip install transformers torch
from transformers import AutoTokenizer, AutoModel
import torch
ck = "InstaDeepAI/nucleotide-transformer-v2-500m-multi-species"
tok = AutoTokenizer.from_pretrained(ck)
m   = AutoModel.from_pretrained(ck).eval().cuda()
seq = "ACGT" * 200           # 800 bp toy
inp = tok(seq, return_tensors="pt").to("cuda")
with torch.no_grad():
    out = m(**inp, output_hidden_states=True)
emb = out.hidden_states[-1].mean(dim=1)        # (1, 1024)
print(emb.shape)
# In-silico mutagenesis
def delta(ref, alt, pos):
    seq_alt = ref[:pos] + alt + ref[pos+1:]
    inp2 = tok(seq_alt, return_tensors="pt").to("cuda")
    e2 = m(**inp2, output_hidden_states=True).hidden_states[-1].mean(1)
    return (e2-emb).norm().item()
print("effect:", delta(seq, "G", 100))
library(reticulate)
trans <- import("transformers"); torch <- import("torch")
ck   <- "InstaDeepAI/nucleotide-transformer-v2-500m-multi-species"
tok  <- trans$AutoTokenizer$from_pretrained(ck)
mdl  <- trans$AutoModel$from_pretrained(ck)$eval()$cuda()
seq  <- paste(rep("ACGT",200), collapse="")
inp  <- tok(seq, return_tensors="pt")$to("cuda")
out  <- mdl$forward(input_ids=inp$input_ids, output_hidden_states=TRUE)
emb  <- out$hidden_states[[25]]$mean(dim=1L)
cat("emb dim:", emb$shape, "\n")
決策樹

什麼任務該選哪個模型？

任務類型？

①→表現量 / 染色質：Enformer / Borzoi。Expression / chromatin: Enformer / Borzoi.
②→變異致病性 / 罕病：AlphaMissense + PrimateAI-3D（見 Ch08）。Variant pathogenicity / rare disease: AlphaMissense + PrimateAI-3D (Ch08).
③→短調控元件分類：DNABERT-2 / NT-v2。Short regulatory classification: DNABERT-2 / NT-v2.
④→100 kb+ 長序列 + 算力有限：Caduceus。100 kb+ long with limited compute: Caduceus.
⑤→非編碼變異 QTL：Enformer/Borzoi + GPN-MSA 集成。Non-coding QTL: Enformer/Borzoi + GPN-MSA ensemble.

本章小測 (3 題)

1. Caduceus 的核心架構特色是？

1. Caduceus's core architectural feature is?

A. Vanilla Transformer
B. Mamba 狀態空間 + 反向互補等變性B. Mamba state-space + reverse-complement equivariance
C. CNN with PWM
D. RNN with attention
B 正解。SSM + RC 等變讓長 DNA 建模又準又快。B. SSM + RC equivariance gives accurate & fast long-DNA modeling.

2. 「In-silico mutagenesis」是？

2. "In-silico mutagenesis" is?

A. 真實的細胞編輯實驗A. Real cell-editing experiment
B. 用模型對 ref vs alt 序列推論，記錄輸出差異作為變異效應B. Run ref vs alt through a model and use the output delta as the variant effect
C. PCR primer 設計
D. CRISPR screen
B 正解。ISM 是序列 AI 最常用的解釋方法之一。B. ISM is one of the most common interpretability tools for sequence AI.

3. 為何 2024 benchmark 顯示「沒有單一模型在所有任務勝出」？

3. Why does the 2024 benchmark show "no model wins all tasks"?

A. 沒人會調參A. No one knows how to tune
B. 不同任務需要不同的 inductive bias（功能監督 vs 進化保守）B. Different tasks need different inductive biases (functional supervision vs evolutionary conservation)
C. 因為 benchmark 設計有錯C. The benchmark is flawed
D. 因為 Caduceus 還沒釋出D. Caduceus wasn't released yet
B 正解。不同任務本質就是「不同的歸納偏好最契合」。B. Different tasks favor different inductive biases.
