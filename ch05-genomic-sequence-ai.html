動機

DNA 為什麼可以被「語言模型」建模？

表面上 DNA 只有 4 個字母（A/C/G/T），但啟動子、增強子、剪接位、CpG 島等「文法」隱藏在序列中。距離可達 100 kb 以上的調控元件能影響一個基因的表現量——這正是 Transformer 「自注意力」最擅長捕捉的長程依賴。

傳統 motif 掃描或 PWM 只能看局部訊號；現代序列 AI 把整段 DNA 當作上下文，輸出可以是 chromatin accessibility、表現量、變異效應等多種「軌道 (tracks)」。Avsec 2021 的 Enformer 把 context 拉到 196 kb 後，遠端增強子–啟動子相互作用的預測首次超越 CNN baseline 30+ percentage points。

DNA has only 4 letters (A/C/G/T), but promoters, enhancers, splice sites, CpG islands hide an entire "grammar". Regulatory elements >100 kb away can modulate a gene's expression — exactly the long-range dependencies Transformer self-attention excels at.

Traditional motif-scanning or PWMs see only local signals; modern sequence AI treats long DNA as context and outputs many "tracks": chromatin accessibility, expression, variant effects, and more. Avsec 2021's Enformer pushed context to 196 kb and beat CNN baselines on distal enhancer–promoter interactions by 30+ percentage points.

DNA 從來不是「點對點查表」——它的功能寫在 100 kb 的長程結構裡，而我們直到 2021 年才有適合的工具看見這件事。 — Avsec et al., Nat Methods 2021
DNA was never "lookup-table biology" — its function lives in 100-kb-scale structure, and we only got the right tools to see that in 2021. — Avsec et al., Nat Methods 2021

DNA 模型到底在「學」什麼？三層說明

🌱 新手版本

想像你給模型 1 萬條 DNA 段落，並隨機把其中 15% 的鹼基蓋住請它猜。猜久了它就學會：「轉錄因子結合位附近常有特定 motif」「啟動子在 TSS 附近 GC 偏高」這些規則。學會這些之後，它就能對新序列預測「這裡可能是啟動子嗎？」

Imagine handing the model 10K DNA snippets and masking 15% of bases for it to guess. After enough practice it learns rules: "TFBS motifs cluster", "GC bias near TSS." Then for a new sequence it can answer: "Is this likely a promoter?"

🎓 中階版本

DNA Foundation Model 用 masked language modeling (MLM) 或 causal LM 兩種預訓練。輸入單字符（NT v1）、6-mer（NT v2 / DNABERT-1）、BPE（DNABERT-2）或者 byte-level token。下游任務用 linear probe / LoRA / full FT 微調，或乾脆 zero-shot 用 ISM。

DNA FMs use masked language modeling (MLM) or causal LM. Tokens are single-char (NT v1), 6-mer (NT v2 / DNABERT-1), BPE (DNABERT-2), or byte-level. Downstream: linear probe / LoRA / full FT, or zero-shot via ISM.

🔬 進階版本

Caduceus 用 Mamba (S4 state-space) 把 attention 的 O(N²) 變成 O(N log N)，並加上「反向互補等變性 (RC-equivariance)」——對 DNA 雙股結構天生公平。BEND 2024 benchmark 顯示：在 enhancer / promoter / chromatin 任務，supervised CNN (Basenji2) 仍能與 FM 持平；但變異效應 (ISM) 與遠端 cis-regulation 是 FM 真正贏的地方。

Caduceus uses Mamba (S4 state space) to swap attention's O(N²) for O(N log N), plus reverse-complement (RC) equivariance — fair to DNA's double-strand nature by construction. BEND 2024: supervised CNNs (Basenji2) match FMs on enhancer / promoter / chromatin; FMs win clearly on variant effect (ISM) and distal cis-regulation.

典型使用流程

選模型與 token 化

NT-v2 用 6-mer + BPE；Caduceus 用單字符。任務若涉及短距 motif，6-mer 更有效；涉及超長序列，單字符 + Mamba 更省。

NT-v2 uses 6-mer + BPE; Caduceus uses single-character. Short motifs → 6-mer; ultra-long → single-char + Mamba.

嵌入抽取或微調

少資料情境用 zero-shot 嵌入接線性分類器；資料夠用 LoRA / full FT。

Few-shot: zero-shot embeddings + linear probe; ample data: LoRA / full fine-tune.

變異效應預測（ISM）

在序列上做 ref vs alt 推論，記錄輸出差異作為 delta-score。

Run ref vs alt through the model; the output delta is the variant effect score.

與 GWAS / QTL 整合

用模型分數做 functional fine-mapping，或當作 PRS 的補充特徵。

Use scores for functional fine-mapping or as auxiliary features in PRS.

想再深一點？MSA + Evoformer 與 attention 的複雜度危機

為什麼基因體模型不像 AlphaFold 一樣用 MSA？

AlphaFold 2 的 Evoformer 把同源蛋白的 MSA 編碼為「成對 (pairwise)」表示——每行是一條同源序列，每列是一個位置。利用共保 (co-evolution) 訊號（兩個位置常一起突變 = 結構上接觸）解出 3D 摺疊。數學上：

attn(Q, K, V) = softmax(QKᵀ / √d) · V

注意力的問題在於 QKᵀ 是 O(N²)。對 200 個 residue 的蛋白，N²=40,000 個 entries——CPU 都能跑。但對 100 kb DNA，N=100,000，QKᵀ 矩陣有 100 億 entries，A100 80 GB GPU 也塞不下。Enformer 之所以用「local attention + dilation」就是要繞開這條牆。

第二個問題：DNA 沒有像蛋白質那樣豐富的 MSA。pan-mammal 保守訊號被 GERP / phyloP / GPN-MSA 利用，但跨物種 alignment 在重複序列、超長 intron、TE 區域常崩潰。所以 DNA FMs 多半改用「全序列 LM」+「conservation track 作為 auxiliary loss」（如 GPN-MSA, Benegas 2024）。

Mamba / S4 的數學直覺：把 attention 換成選擇性狀態空間：
ht = A·ht-1 + B·xt, yt = C·ht
