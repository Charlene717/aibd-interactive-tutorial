變異解讀與罕病診斷

AlphaMissense、PrimateAI-3D、ESM1b——把 7100 萬個錯義變異一次標好致病性，然後呢？

AlphaMissense, PrimateAI-3D, ESM1b — pathogenicity labels for 71M missense variants. Now what?

背景

罕病診斷的核心難題：VUS

臨床基因檢測常見的瓶頸不是「找不到變異」，而是 VUS（Variant of Uncertain Significance）——找到了，但不知道是不是致病。ClinVar 大約 50% 提交為 VUS。AI 變異效應預測器 (VEP) 的工作就是把「不確定」往「可能致病 / 可能良性」推。

2023 年 Science 封面：AlphaMissense 涵蓋人類 7100 萬個錯義變異，AUROC ≈ 0.96，覆蓋率前所未見。同年 Illumina 推 PrimateAI-3D，用非人靈長類變異訓練。2024 起 Meta ESM1b / ESM-3 用語言模型 zero-shot 給分。

The bottleneck in clinical genetic testing isn't "no variant found" — it's VUS (Variant of Uncertain Significance): variant found but pathogenicity unclear. ~50% of ClinVar submissions are VUS. AI variant effect predictors (VEPs) push "uncertain" toward "likely pathogenic / likely benign".

Science cover 2023: AlphaMissense covers all 71M human missense variants at AUROC ≈ 0.96. The same year, Illumina launched PrimateAI-3D, trained on non-human primate variants. Since 2024, Meta's ESM1b / ESM-3 provides zero-shot scores via language modeling.

Don't take benchmark AUROC as clinical truth.
ACMG 整合

AI 分數與 ACMG 規範

ACMG/AMP 2015 框架把致病性分成 P/LP/VUS/LB/B，每條證據有 PVS / PS / PM / PP（致病）與 BA / BS / BP（良性）等強度。AI 分數通常落在 PP3（電腦預測支持致病）/ BP4（電腦預測支持良性）。2023 修訂的 SVI (Sequence Variant Interpretation) workgroup 文件給了 quantitative thresholds：

  • AlphaMissense ≥ 0.564 ⇒ PP3_Strong；≤ 0.34 ⇒ BP4_Strong（依 cohort 校準）。
  • AlphaMissense ≥ 0.564 ⇒ PP3_Strong; ≤ 0.34 ⇒ BP4_Strong (cohort-calibrated).
  • REVEL ≥ 0.932 ⇒ PP3_Very Strong；≤ 0.016 ⇒ BP4_Very Strong。
  • REVEL ≥ 0.932 ⇒ PP3_Very Strong; ≤ 0.016 ⇒ BP4_Very Strong.
  • SpliceAI ≥ 0.5 ⇒ PP3 for splice region；< 0.1 ⇒ BP4。
  • SpliceAI ≥ 0.5 ⇒ PP3 splice; < 0.1 ⇒ BP4.
實作

查詢一個變異的多源 AI 預測

# Approach 1: dbNSFP via myvariant.info
import myvariant
mv = myvariant.MyVariantInfo()
r = mv.getvariant("chr7:g.140453136A>T",
                  fields="dbnsfp.alphamissense,dbnsfp.primateai,dbnsfp.revel,dbnsfp.cadd_phred")
print(r["dbnsfp"])

# Approach 2: download bulk AM tsv
# https://storage.googleapis.com/dm_alphamissense/AlphaMissense_aa_substitutions.tsv.gz
library(myvariant)
mv <- MyVariant()
r <- getVariant(mv, "chr7:g.140453136A>T",
        fields="dbnsfp.alphamissense,dbnsfp.primateai,dbnsfp.revel,dbnsfp.cadd_phred")
print(r$dbnsfp)
💡
實務原則：不要只看一個分數。建議至少參考 3 個（如 AlphaMissense + REVEL + ESM1b）並把分歧值報告給臨床遺傳師。可在 dbNSFP v4.6 直接取得 50+ VEP 分數。 Rule of thumb: Never rely on a single score. Use at least 3 (e.g., AlphaMissense + REVEL + ESM1b) and report disagreements to the clinical geneticist. dbNSFP v4.6 includes 50+ VEPs.
罕病工作流

家系 WGS → 報告的 6 步驟

WGS + GATK best practice

DeepVariant 或 GATK HaplotypeCaller；trio 模式可大幅降偽陽性。

DeepVariant or GATK HaplotypeCaller; trio mode greatly reduces false positives.

VEP / SnpEff 註釋

註明 transcript / consequence；同時 join AlphaMissense、REVEL、SpliceAI。

Annotate transcript / consequence; join AlphaMissense, REVEL, SpliceAI scores.

表型對照

用 Exomiser / LIRICAL / AMELIE 對齊 HPO 表型與基因。

Use Exomiser / LIRICAL / AMELIE to align HPO terms with genes.

家系分離分析

驗證孟德爾遺傳模式（隱性/顯性/X-linked），縮小候選清單。

Validate inheritance (recessive/dominant/X-linked) to narrow candidates.

ACMG 分類

綜合 PVS/PS/PM/PP/BP/BS 證據；AI 分數歸於 PP3 / BP4 強度。

Combine PVS/PS/PM/PP/BP/BS evidence; AI scores go under PP3 / BP4 strength.

臨床確認 + 報告

Sanger 驗證、回饋家庭、若有家族風險變異提供遺傳諮詢。

Sanger confirm, return results to family, provide genetic counseling for familial-risk variants.
